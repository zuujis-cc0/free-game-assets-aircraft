# Aircraft models: Zuujis free game assets

24 aircraft models in binary glTF (GLB), self-contained, for flight games, scenery and prototypes. Public-domain **CC0**: use them in commercial or personal games. Credit is optional.

Every file is here on its own: open one on GitHub and use **Download raw file** to save just that file. Or download the whole pack:

**[Download zuujis-aircraft-glb.zip](https://github.com/zuujiscom/free-game-assets/releases/download/v1.0.0/zuujis-aircraft-glb.zip)** · [Preview gallery](https://github.com/zuujiscom/free-game-assets/blob/main/previews/aircraft/README.md) · [All Zuujis packs](https://github.com/zuujiscom/free-game-assets)

[CC0 terms](LICENSE) · [Credits](CREDITS.md) · [Report how you used them](https://github.com/zuujiscom/free-game-assets/issues/new?template=asset-use.yml)

```sh
git clone --depth 1 https://github.com/zuujiscom/free-game-assets-aircraft
```
